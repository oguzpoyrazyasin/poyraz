# Poyraz Kids

Poyraz Kids is a privacy-first Android learning hub for children aged 2–6.

## Product principles
- Age-based content: 2–3, 3–4, 4–5, 5–6
- Development areas: language, cognitive skills, fine motor, early maths, creativity, movement
- Curated smart-game and educational-video links
- Parent gate before opening external content
- No ads, analytics, accounts, location, camera, microphone or personal-data collection in v1
- Turkish-first interface
- Google Play readiness: targetSdk 36

> Parent supervision is required. External links are opened only after a parent gate. Content providers remain responsible for their own services and privacy practices.

## Status
Android MVP source and CI build are maintained in this repository.
