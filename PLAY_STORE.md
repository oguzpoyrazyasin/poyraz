# Google Play Release Checklist

## Product
- App: Poyraz Kids
- Audience: children aged 2–6 and their parents/guardians
- Category: Education
- Monetization: none in v1
- Ads: none
- Accounts: none
- Target SDK: 36

## Families / safety design
- Parent gate before external links
- No ad SDK
- No analytics SDK
- No sensitive permissions
- No child profile or personal information
- External content is explicitly labeled and parent-mediated

## Before Play Console submission
1. Configure Play App Signing.
2. Build a signed Android App Bundle (AAB).
3. Complete Data safety accurately.
4. Complete Target audience and content; declare child age groups.
5. Complete Families Policy declarations.
6. Add screenshots, 512x512 icon, feature graphic and support contact.
7. Host a public privacy-policy URL.
8. Review every external provider for child-directed suitability in each distribution market.
9. Run closed testing before production rollout.

## Suggested store description
Poyraz Kids helps parents guide children aged 2–6 through short, age-appropriate learning activities. Explore language, early maths, problem solving, creativity and movement with curated educational links and practical parent prompts. External content opens only after a parent check.
